# Code of conduct

We want technical disagreement to be direct, evidence-seeking, and safe for
participation. Be respectful, critique claims and artifacts rather than people,
state uncertainty, preserve material dissent, and do not use source authors as
personas or authority votes.

Harassment, threats, discriminatory conduct, doxxing, deliberate disclosure of
private information, and sustained disruption are not acceptable. Maintainers
may edit, hide, or remove contributions and restrict participation when needed
to protect the project and its contributors.

Report conduct concerns privately to the maintainers through the contact path
on the Kizz GitHub organization. Security vulnerabilities belong in private
vulnerability reporting instead.
